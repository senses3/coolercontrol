CoolerControl apt repository

This host serves Debian and Ubuntu packages for CoolerControl. It is a package repository, not a website, so there is nothing to browse here.

Set it up

curl -fsSL https://apt.coolercontrol.org/setup.sh | sudo sh
sudo apt install coolercontrol

The script picks the right package tree for your distribution, installs the signing key and writes the apt source. Full instructions, including other distributions, are in the installation guide.

Packages

coolercontrol Desktop application
coolercontrold Daemon, installed automatically with the above
liquidctl-git Newer liquidctl, for distributions carrying an outdated one
it87-dkms Out of tree it87 driver, many Gigabyte boards
nct6687d-dkms Out of tree nct6687 driver, many MSI and ASUS boards
arctic-fan-controller-dkms ARCTIC fan controller driver, for kernels older than 7.2

Layout

Two trees, /debian for Debian based systems and /ubuntu for Ubuntu based ones, each serving amd64 and arm64 from the stable suite. Every published version is kept, so an older one can still be installed with apt install coolercontrold=<version>.
